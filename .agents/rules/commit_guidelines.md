# ข้อกำหนดการเขียน Git Commit Message

ทุกครั้งที่มีการบันทึก Git Commit ให้ใช้ภาษาไทย และจัดโครงสร้างข้อความสรุปให้ชัดเจน เข้าใจง่าย เหมือนสรุปรายงาน (Doc) ดังนี้:

### โครงสร้าง Commit Message:
```text
[ประเภท] หัวข้อการแก้ไขหรือฟังก์ชันภาษาไทยที่กระชับ

รายละเอียดการเปลี่ยนแปลง:
- รายการที่ 1: อธิบายสิ่งที่แก้ไขหรือเพิ่มเข้ามา
- รายการที่ 2: ระบุข้อผิดพลาดที่แก้ (Bug Fixes) หรือการปรับปรุง (Improvements)
- รายการที่ 3: ไฟล์หรือโมดูลที่เกี่ยวข้อง
```

### ตัวอย่าง:
```text
[แก้ไข] ปรับปรุงระบบนำเข้าข้อมูลสมาชิก Bulk Import และแก้ปัญหาความเข้ากันได้ของฐานข้อมูล

รายละเอียดการแก้ไข:
- เพิ่มการสร้าง UUID อัตโนมัติในตาราง users และ members ป้องกันข้อผิดพลาด Duplicate Key
- แก้ไขการดึงวันที่เริ่มเป็นสมาชิก (join_date) ในไฟล์ CSV
- ปรับแต่งการส่ง CSRF Token ผ่าน AJAX ในหน้าจอเจ้าหน้าที่
- รองรับการกรองเครื่องหมายลูกน้ำและสกุลเงินในไฟล์ Excel
```
